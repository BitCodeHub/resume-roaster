# Resume Roaster - Enterprise SaaS Redesign Brief
**Date:** 2026-02-04
**Objective:** Transform Resume Roaster into enterprise-grade SaaS product

## Competitive Analysis Summary

### Direct Competitors
1. **Rezi** ($29/mo, $149 lifetime)
   - 4M+ users (prominently displayed)
   - Feature-heavy interface
   - AI-powered tools
   - Clean white/blue design
   - Extensive social proof

2. **Resume Worded** ($49/mo)
   - Instant feedback focused
   - Minimal design
   - Free tier to hook users
   - LinkedIn optimization

3. **Jobscan** ($49.95/mo)
   - ATS optimization focus
   - Professional interface
   - Job tracking features

### Enterprise SaaS Benchmarks
1. **Stripe**
   - Data-driven trust signals ($1.4T processed, 99.999% uptime)
   - Purple/blue gradient palette
   - Customer logos (recognizable brands)
   - Enterprise credibility

2. **Linear**
   - Minimal, modern design
   - Fast, purpose-built messaging
   - Subtle gradients
   - Clean black/white with accent color

## Design System

### Color Palette
**Primary:** Deep Navy `#0A1628` (professional, trustworthy)
**Accent:** Coral `#FF6B5A` (warm, action-oriented)
**Secondary:** Electric Blue `#3B82F6` (modern, tech-forward)
**Success:** Green `#10B981`
**Background:** Off-white `#FAFAFA`
**Text:** Dark Gray `#1F2937`, Light Gray `#6B7280`

### Typography
- **Headings:** Inter (700, 600)
- **Body:** Inter (400, 500)
- **H1:** 4rem (64px) desktop, 2.5rem mobile
- **H2:** 3rem (48px) desktop, 2rem mobile
- **H3:** 2rem (32px)
- **Body:** 1.125rem (18px) - larger for readability
- **Small:** 0.875rem (14px)

### Spacing System
- Base: 8px
- Scale: 8, 16, 24, 32, 48, 64, 96, 128px
